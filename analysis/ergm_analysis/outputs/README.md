# ERGM Analysis Results

本目录包含使用指数随机图模型（ERGM）对GitHub社交网络进行结构分析的结果，主要关注网络形成机制和结构特征。

## 1. ERGM模型概述

指数随机图模型（Exponential Random Graph Models, ERGM）是一种用于分析网络形成机制的统计模型，通过评估不同结构特征对网络形成的影响权重，揭示网络的形成规律。

## 2. 分析结果

### 2.1 度分布分析
- **degree_distribution.png**：网络节点的度分布直方图，展示不同度值的节点数量分布

### 2.2 共同邻居分布
- **edgesharedpartners_distribution.png**：边共享伙伴（共同邻居）数量的分布，反映网络中三角闭合的倾向

### 2.3 幂律拟合
- **power_law_fit.png**：网络度分布的幂律拟合结果，包括原始数据点和拟合曲线

## 3. 结果解读

### 3.1 度分布特征
- **无标度特性**：从degree_distribution.png可以观察到，网络度分布呈现明显的右偏特征，少数节点拥有大量连接，而大多数节点连接数较少
- **幂律拟合**：power_law_fit.png显示网络度分布较好地符合幂律分布，这是许多真实社交网络的典型特征

### 3.2 结构形成机制
- **三角闭合倾向**：edgesharedpartners_distribution.png展示了边共享伙伴的分布，反映了网络中三角闭合的普遍存在
- **传递性**：较高的边共享伙伴数量表明网络具有较强的传递性，即"朋友的朋友更可能成为朋友"

### 3.3 ERGM模型参数
虽然未直接输出参数文件，但ERGM分析通过以下结构特征解释网络形成：
- **度分布**：节点连接数量的分布
- **三角闭合**：两个节点通过共同邻居建立连接的倾向
- **边共享伙伴**：边之间共享的共同邻居数量

## 4. 应用价值

1. **网络形成理解**：揭示GitHub社交网络的形成机制和演化规律
2. **模型验证**：验证真实网络是否符合理论模型的预测
3. **网络生成**：基于ERGM模型参数生成具有相似结构特征的合成网络
4. **异常检测**：识别偏离ERGM模型预测的异常节点或边
5. **网络设计**：为人工网络设计提供理论指导

## 5. 生成方法

所有结果由`ergm_graphtool_analysis.py`脚本生成，使用graphtool库实现ERGM模型分析。

使用的主要分析方法：
- 度分布计算与可视化
- 边共享伙伴分布分析
- 幂律分布拟合与检验
- ERGM模型参数估计

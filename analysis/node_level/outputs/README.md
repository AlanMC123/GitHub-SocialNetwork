# Node Level Analysis Results

本目录包含GitHub社交网络节点级分析的结果，主要关注节点的属性、中心性和影响力等特征。

## 1. 节点级分析概述

节点级分析是对网络中单个节点的属性和行为进行深入研究，包括节点的基本特征、中心性、影响力等。本次分析旨在揭示GitHub社交网络中开发者节点的关键特征。

## 2. 分析结果

- **results.csv**：节点级分析的主要结果，包含每个节点的各种属性和指标

## 3. 结果内容

results.csv文件包含以下主要指标：

### 3.1 基本节点属性
- 节点ID：唯一标识
- 节点类型：开发者类型
- 度：节点的连接数量（入度、出度、总度）

### 3.2 中心性指标
- 度中心性：节点连接的直接影响力
- 介数中心性：节点在网络中的桥梁作用
- 接近中心性：节点到达其他节点的平均距离
- 特征向量中心性：节点的全局影响力
- PageRank：节点的重要性评分

### 3.3 其他属性
- 聚类系数：节点的局部聚类程度
- 社区归属：节点所属的社区
- 活跃度：节点的活动程度

## 4. 结果解读

### 4.1 节点特征分布
- 从results.csv可以分析节点各种属性的分布特征
- 识别出网络中的核心节点和边缘节点
- 发现节点特征之间的相关性

### 4.2 中心性分析
- 度中心性高的节点是网络中的活跃参与者
- 介数中心性高的节点是网络中的关键桥梁
- 特征向量中心性高的节点具有广泛的影响力
- PageRank高的节点是网络中的重要枢纽

## 5. 应用价值

1. **核心节点识别**：识别网络中的关键开发者和影响力人物
2. **节点分类**：基于节点属性和中心性进行开发者分类
3. **影响力评估**：评估每个开发者在网络中的影响力
4. **网络结构优化**：基于节点分析结果优化网络结构
5. **推荐系统**：基于节点特征改进开发者推荐算法

## 6. 生成方法

所有结果由`node_level_analysis.py`脚本生成，使用以下技术栈：
- **网络分析**：NetworkX
- **数据处理**：Pandas
- **中心性计算**：NetworkX算法

## 7. 使用说明

- results.csv包含了完整的节点级分析结果，可以直接用于后续分析
- 可以根据需要筛选特定指标或节点进行深入研究
- 结果可以与其他分析模块的结果结合使用，如社区分析、影响力传播分析等

# Node Classification Results

本目录包含使用图神经网络（GNN）对GitHub社交网络节点进行分类的结果，以及节点特征重要性分析。

## 1. 节点分类概述

节点分类的目标是根据节点的特征和网络结构，预测节点的类别标签。本次分析使用了多种GNN模型来预测GitHub开发者的类型。

## 2. GNN模型

本次分析使用了以下GNN模型：
- Graph Convolutional Network（GCN）
- GraphSAGE
- Graph Attention Network（GAT）

## 3. 分析结果

### 3.1 特征重要性分析
- **feature_importance.csv**：节点特征的重要性排序，包括特征名称和重要性得分
- **feature_importance.png**：特征重要性的可视化柱状图，直观展示各特征对分类的贡献

### 3.2 模型性能比较
- **model_comparison.csv**：不同GNN模型的性能指标对比，包括准确率、精确率、召回率、F1分数等

## 4. 结果解读

### 4.1 特征重要性
- 从feature_importance.csv和feature_importance.png可以看出，哪些节点特征对开发者类型分类最为关键
- 高重要性特征反映了GitHub开发者的关键属性，如活跃度、影响力、协作模式等
- 特征重要性分析有助于理解GitHub社交网络中开发者的核心特征

### 4.2 模型性能
- 从model_comparison.csv可以看出不同GNN模型的优缺点
- GAT模型通常表现较好，因为它能够学习节点间的注意力权重，更好地捕捉重要连接
- 不同模型的性能差异可能与网络结构和节点特征的复杂程度有关

## 5. 应用价值

1. **开发者画像**：基于节点分类结果构建更准确的开发者画像
2. **特征工程指导**：根据特征重要性优化后续分析的特征选择
3. **模型选择参考**：为实际应用选择最合适的GNN模型
4. **异常检测**：识别具有异常特征组合的开发者节点
5. **推荐系统**：基于分类结果改进开发者推荐算法

## 6. 生成方法

所有结果由`node_classification.py`脚本生成，使用以下技术栈：
- **GNN模型**：PyTorch Geometric
- **特征重要性**：基于模型输出的特征贡献度分析
- **评估指标**：scikit-learn

## 7. 使用说明

### 7.1 特征重要性应用
- 高重要性特征可用于简化后续分析，提高模型效率
- 可根据特征重要性设计更有针对性的数据收集策略

### 7.2 模型选择
- 根据model_comparison.csv选择最适合特定任务的GNN模型
- 考虑准确率、计算效率等因素综合决策
